# Simple Web Text Utility

This example demonstrates how to build a small, interactive web utility using basic HTML, CSS, and JavaScript. It allows users to input text and apply common string operations like converting to uppercase, lowercase, reversing, and counting words. This project encourages moving beyond passive tutorial consumption to actively applying learned concepts in a concrete way.

## Language

`html`

## How to Run

Save the code as `index.html`.
Open `index.html` in any modern web browser.
